# 达斡尔族知识大乱斗

一个单页的达斡尔族文化知识答题战斗小游戏。

玩家从三位英雄中选择一位，与雾团兽「阿雾」进行五题知识对决：

- 答对：英雄发动攻击，敌人扣血。
- 答错：雾团兽反击，英雄扣血，并显示正确答案与解析。
- 任意一方 HP 归零即结算胜负。

## 英雄特性

- **莫日根 · 鹰眼暴击**：每局第一次答对造成 55 点暴击伤害。
- **库木勒 · 柳芽护盾**：每次答对获得 5 点护盾，优先抵挡反击伤害。
- **贝阔 · 贝阔连击**：连续答对伤害递增 +6，答错后连击重置。

## 操作

- 点击选项即可作答。
- 也可以按 A / B / C / D 或 1 / 2 / 3 / 4 选择答案。
- 右上角可开启/关闭音效，也可复制分享链接。

## 技术

纯单文件 HTML + CSS + JavaScript，无外部依赖。音效使用 Web Audio API 程序化合成。
