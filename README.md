# 达斡尔族知识大乱斗 · 赤焰试炼

在线试玩：[https://x15737876973-art.github.io/daur-quiz/](https://x15737876973-art.github.io/daur-quiz/)

![游戏封面](./og.png)

一个单页的达斡尔族文化知识答题战斗小游戏：**5 位英雄、每位 5 套可换衣装、100 道文化题；随机抽题直到击破会进化的雾团兽。**

玩家选择射手、法师或战士，与雾团兽「阿雾」进行一场必须分出胜负的知识对决：

- 答对：英雄施展本职业专属攻击，雾团兽扣血并露出痛苦表情；英雄的脸也会根据性格绘制成不同样式。
- 答错：雾团兽反击并累积「连续答错」层数；层数越高，它越危险。
- **只有把雾团兽的 HP 打到 0 才算胜利**；英雄 HP 归零则失败。
- 每 10 题重新随机抽取一组题继续战斗，不再以答题数量判定胜负。
- 每题作答后都会显示正确答案与解析。

## 雾团兽的进化链

| 连续答错 | 形态 / 攻击 | 表现 |
| --- | --- | --- |
| 1 次 | 兽爪突进 | 冲到英雄面前挥出三连兽爪，再退回原位。 |
| 2 次 | 炽焰喷吐 | 喷出大范围火焰，露出得意的半眯眼与坏笑。 |
| 3 次 | 翼焰形态 · 裂空翼斩 | 长出赤焰双翼，使用翼刃攻击；**翅膀形态会一直保留**。 |
| 4 次 | 终极形态 · 熔火领主 | 再长出两只长角，仰天大吼并召唤带岩浆的陨石雨。 |

## 五位英雄与职业

| 英雄 | 职业 | 专属特性 |
| --- | --- | --- |
| 莫日根 | 射手 | 鹰眼：本局第一次答对必定暴击，射出 43 点伤害的赤羽箭。 |
| 塔娜 | 射手 | 连珠箭：连续答对时每箭额外 +6 伤害，答错重置。 |
| 库木勒 | 法师 | 柳芽护盾：每次答对获得 7 点护盾，最多 28 点，优先抵挡兽爪。 |
| 乌春 | 法师 | 星火共鸣：每第三次答对追加 16 点星火伤害。 |
| 贝阔 | 战士 | 圣剑裁决：每第三次答对伤害翻倍，劈出 60 点至圣伤害。 |

五位英雄的脸部按背景分别绘制：莫日根的鹰眼与猎人疤痕、塔娜的雀斑与笑窝、库木勒的柳叶面纹、乌春的火焰面纹、贝阔的战士疤痕与爽朗笑容。受到攻击时，每位英雄都会切换成各自的受伤痛苦表情。

## 衣装与题库

- 每位英雄有 **5 套衣装**，共 25 套；款式、配色、披风/短袄/披巾/战袍/斗篷结构会随之变化。
- 题库共 **100 道**，分为 5 个互不重复的 20 题专属题库。
- 战斗以 10 题为一组随机抽取；一组答完后自动重抽下一组，直到雾团兽或英雄倒下。
- 每局重新抽题并打乱选项，重玩不会固定顺序。

## 操作

- 点击选项即可作答。
- 也可以按 A / B / C / D 或 1 / 2 / 3 / 4 选择答案。
- 右上角可开启/关闭音效，也可复制分享链接。
- 「重新选择」可随时回到英雄与衣装选择页。

## 技术

纯单文件 HTML + CSS + JavaScript，无外部依赖。角色、怪兽、双翼、长角与武器均为内联 SVG；攻击特效由 CSS 动画分层合成；音效使用 Web Audio API 程序化合成，并通过压缩器与混响控制响度。
